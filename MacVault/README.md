# MacVault – Personal Password & Notes Manager

MacVault is a modern, macOS-inspired personal information
organizer built with HTML, CSS, and vanilla JavaScript.

## Features

- Add and edit password entries.
- Add and edit personal notes.
- Show and hide passwords.
- Generate random passwords.
- Copy passwords and notes to clipboard.
- Search saved entries.
- Filter passwords and notes.
- Sort entries alphabetically or by date.
- Delete saved entries.
- Dark and light themes.
- Browser local storage persistence.
- Responsive interface.

## Technologies

- HTML5
- CSS3
- JavaScript
- Browser Local Storage
- Clipboard API
- Web Crypto API

## Getting Started

1. Clone or download the project.
2. Open the project folder in VS Code.
3. Open index.html in Google Chrome.
4. Start adding sample passwords and notes.

## Security Notice

This project is an educational frontend prototype.
Data is stored in browser local storage without encryption.
Do not use real passwords or confidential information.
